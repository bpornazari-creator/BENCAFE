# بن‌کافه — نسخه آغازین Expo

این شاخه یک پایه واقعی React Native با Expo SDK 58 برای ادامه توسعه بن‌کافه فراهم می‌کند.

## اجرا
1. Node.js نسخه 22.13 یا بالاتر نصب باشد.
2. در ریشه پروژه اجرا کنید:
   `npm install`
3. سپس:
   `npx expo start`

برای ساخت خروجی Android/iOS در مرحله بعد باید پروژه به حساب Expo/EAS متصل و build profile تنظیم شود.

## وضعیت فعلی
- صفحه خانه با هویت بصری زرشکی و طلایی
- مسیرهای داخلی خانه، منو، مافیا و سفارش‌ها
- رابط فارسی با چیدمان راست‌به‌چپ
- منو، سانس‌ها، ثبت سفارش، ورود کاربر، پرداخت و پنل مدیریت هنوز به داده و سرویس واقعی متصل نیستند.

## نکته
این نسخه پایه رابط کاربری است؛ سفارش یا پرداخت واقعی انجام نمی‌دهد. اطلاعات واقعی منو، قیمت‌ها، برنامه سانس‌ها، روش تحویل و تنظیمات کسب‌وکار باید پیش از فعال‌سازی قابلیت‌های عملیاتی وارد شوند.
